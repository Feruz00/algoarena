# Online Judge Platform

A full-stack Online Judge system for competitive programming.

## Project Structure

## Tech Stack

- **Frontend (Client)**: React
- **Admin Panel**: React
- **Backend**: Node.js + Express
- **Judge Service**: Node.js
- **Database**: (MongoDB / PostgreSQL / MySQL – update this)

## Features

- User authentication & authorization
- Problem management (CRUD)
- Code submission
- Real-time judging
- Leaderboard
- Admin dashboard
- Multi-language support (C++, Python, Java, etc.)

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Database (MongoDB / PostgreSQL)
